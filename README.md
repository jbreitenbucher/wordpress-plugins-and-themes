# WordPress Plugins and Themes

A collection of custom WordPress plugins, themes, and utilities built for The College of Wooster's WordPress Multisite environment over 20 years.

## Featured Projects

### LDAP Authentication (`ldap-auth`, `wpdirauth`)
Two custom LDAP authentication plugins that let faculty, staff, and students log into WordPress with their existing campus directory credentials. Both were modernized in 2026 with Claude's help for compatibility with PHP 8.3+ and current WordPress, replacing deprecated functions that had accumulated since they were first built by the original authors.

### Blog Templates (`blogtemplates`)
A site-templating system for WordPress Multisite originally developed by WPMUDev that let a super admin create reusable site templates from any active site in the network, including all existing content. It also added a template-selection step to the site creation screen so users could spin up a new site from a chosen template rather than starting blank. Faculty used this to build course site templates they reused every time they created a new course site. Updated in 2026 for compatibility with current WordPress design practices and PHP 8.3+.
